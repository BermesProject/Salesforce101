# 게임 마케팅 실습

넥슨의 FC 시리즈를 참고한 가상 게임 **킥오프 아레나 3**입니다. 최산은 마케팅 담당 직원이고 우영은 이용자 사례의 주인공입니다. 목표 설치 수와 실제 설치 수, 설치 이후 첫 경기 전환을 비교합니다.

## 준비 순서

1. 공통 Employee와 최산 `EMP-GAME-001`을 확인해 주세요.
2. `schema.json`에 따라 `Game_Marketing_Performance__c`와 필드 14개를 준비해 주세요. 실적 번호는 `GMP-{0000}`입니다. 숫자·날짜 필드의 기본값은 넣지 말아 주세요.
3. 기존 표준 Campaign에 `Training_Campaign_Code__c` Text(40), Unique External ID를 추가해 주세요. Campaign 전체 정의를 대체하지 말아 주세요.
4. 앱 `Game_Marketing_Operations`와 실적 탭, Permission Set `Game_Marketing_Operations_User`를 구성해 주세요. 탐색 항목은 Employee, Campaign, 게임 마케팅 실적입니다.
5. Campaign 사용 권한과 현재 User의 Marketing User 설정을 확인해 주세요. 이 설정이 필요한데 꺼져 있다면 교육생께 설명해 주시고 필요한 변경 범위를 확인해 주세요. 새 User나 Profile 변경으로 우회하지 말아 주세요.
6. `campaigns.csv` 2건을 준비한 뒤 `performance-first10.csv`로 10건을 등록해 주세요. 전체 파일에 포함된 같은 10건입니다.
7. 62%·115% 사례와 공란을 확인한 후 `performance.csv`의 나머지 110건만 추가해 주세요.

## 화면과 계산

입력 영역에는 기준일, Campaign, 채널, 담당 직원, 목표 설치 수, 실제 설치 수, 클릭 수, 첫 경기 완료 인원, 구매 인원, 구매 매출, 검토 상태를 배치해 주세요. 결과 영역에는 목표 달성률·첫 경기 전환율·원본 식별키를 배치해 주세요.

비율 수식과 선택값은 schema.json을 그대로 사용해 주세요. Percent 수식에 100을 곱하지 않습니다. `Performance_Key__c`는 Text(100), Unique External ID이며 데이터 로더/Flow에서 계산합니다. Formula 필드로 바꾸지 말아 주세요. 수식의 공란 처리 설정은 `BlankAsBlank`입니다.

실적 고유키: `YYYY-MM-DD|현재 org의 Campaign.Id|Channel 저장값`입니다. 예시 ID를 복사하지 마시고 실제 조회 결과로 구성해 주세요. 채널 표시명인 영상/커뮤니티 대신 저장값 Video/Community를 사용합니다.

## 화면 Flow 실습

기본 설치에서는 Flow를 미리 완성하거나 활성화하지 않습니다. 수업 단계에서 아래 요청을 사용해 주세요.

```text
Game_Performance_Quick_Entry라는 Screen Flow를 함께 만들어 주세요.
사용자 컨텍스트로 실행하고 기준일, Campaign, 채널, 활성 직원, 목표 설치 수,
실제 설치 수를 필수 입력으로 받아 주세요. 목표는 0보다 크고 실제는 0 이상이어야 합니다.
선택 입력인 클릭 수와 첫 경기 인원은 입력한 경우 0 이상이며,
첫 경기 인원은 실제 설치 수를 넘지 않아야 합니다.
동일한 Performance_Key로 조회하여 0건이면 생성, 1건이면 수정, 2건 이상이면 오류로 중단해 주세요.
수정 전 현재값과 입력값을 보여 주시고 확인 후 저장해 주세요.
선택 입력의 공란은 공란으로 처리해 주시되 기존 값 삭제가 있다면 확인 화면에 표시해 주세요.
화면에서 입력하지 않는 구매 인원·매출은 기존 값을 보존해 주세요.
저장 시 Review_Status는 Submitted로 설정해 주세요.
실패 경로에서는 오류를 보여 주시고 성공 후 저장값을 조회하여 안내해 주세요.
마지막 화면에서는 뒤로 가기를 막아 중복 저장을 방지해 주세요.
```

`Data/screen-entry.xlsx`에서 기존 행 수정부터 실습해 주세요. 반복 실행해도 같은 조합은 1건이어야 합니다. 구매 인원·매출은 후속 분석용 초기 데이터이며 화면 Flow의 수정 대상에서 제외합니다.
